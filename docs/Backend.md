# 这里将教会你 怎么部署后端

[TOC]

**已经默认你下载好了 压缩包并解压

---
1. 打开 `Config.json`
>[!TIP]
> 参数解析
> IP 监听IP地址
> AIURL AI服务器地址
> Model 调用的模型
> Deepthink 是否启用深度思考
> APItype AI模型提供方 本地部署填Ollama
> ApiKey 如果你的AI模型需要Apikey，请把Key放这里
> wenziyingshe OCR识别会存在错别字可以在这里填写正确的

2. 填写参数
3. 运行exe程序
