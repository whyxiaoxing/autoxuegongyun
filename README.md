# 工学云自动化打卡方案

>[!NOTE]
> 工学云 自动化视觉打卡方案 ，不破解云端接口，一台电脑，一个手机，一个局域网就可以实现自动打卡，支持云端部署，超低资源消耗

# 食用教程

>[!WARNING]
> 只支持下面的环境 <br>
> 后端只支持 `Win平台` 前端只支持`Android` <br>
> 其余没有测试
> `apk` 是`Android` 安装包 请在移动端设备下载

>[!TIP]
> 国内各厂商系统不能逐一测试，并且无障碍服务这个权限在程序结束后会自动回收，需要一个 在无障碍服务开启快捷方式，这是权限回收无法突破厂商限制
> 如果有BUG需要你的提交与返回

1. 下载前后端安装包 [下载地址](https://github.com/whyxiaoxing/autoxuegongyun/releases/latest)  分别进行安装
2. 安装好前后端 并配置后端的`Config.json文件`，[后端安装指南点击我跳转](!)[移动端安装指南](!)
3. 运行 `gongxueyunAuto.exe` 程序
4. 打开移动端APP 进入设置界面
5. 点击`服务器链接` 输入服务器端口和IP，点击保存
6. 点击`流程` 右上角`添加`  编排工作流，完成工作流编排后点击保持
7. 点击`首页` 需要开启全部权限， 点击启动即可实现自动化
8. [视频教程](!)


## 安卓权限获取说明
1. 无障碍服务： 为了实现自动化点击需要保证模拟人的操作
2. 悬浮窗，实现App组件中的功能，
3. 电池白名单： 放置在运行过程中导致后台误杀
还有基础的文件读写功能，基础功能不再说明
